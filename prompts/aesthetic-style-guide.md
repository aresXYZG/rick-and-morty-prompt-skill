# 高级提示词模板 - 独立美学版（风格创意）

## 📌 核心理念

**目标**：不提及具体作品名称，而是通过描述视觉美学、制作质感、色彩理论和情感基调来指导AI生成"风格相似但非复制"的内容。这样可以：
- ✨ 获得更自由、更创意的生成结果
- 🎨 避免AI过度模仿原著细节
- 🌟 创造独特的衍生视觉风格
- 📐 保留精致、高质制作的品质

## 🎯 使用策略

### 策略1：精准风格指导而非名字引用
❌ 不要说："Rick and Morty style"
✅ 改为说："sophisticated comedic animation aesthetic with satirical family dynamics"

### 策略2：通过美学类型预设基调
- 在提示词开头明确指定使用哪个美学类型
- 这会影响AI对整体风格、色彩和构图的理解

### 策略3：叠加技术词汇确保质量
- 用"professional"、"sophisticated"、"refined"等词汇重复强调品质
- 用技术词汇指导具体的实现方式

### 策略4：通过否定词避免廉价感
```
Avoid: cheap, crude, simple, amateur, low-budget, basic, sketch-like appearance
```

### 策略5：分层描述创造丰富性
```
1. 场景/环境基础描述
2. 美学风格类型
3. 色彩和光影系统
4. 制作质量标准
5. 技术执行指导
6. 情感和氛围目标
```

## 💡 优化技巧

### 微调方法1：调整细节深度
- **简洁版**：用核心提示词 → 更快生成，风格清晰
- **完整版**：用详细模板 → 更多控制，细节丰富

### 微调方法2：混合美学类型
```
示例：
"Domestic family space [美学类型A] transitioning to surreal environment [美学类型B],
sophisticated animation quality with visual storytelling through color and light design"
```

### 微调方法3：强调特定元素
- 需要更动感？→ 强调"dynamic composition"和"kinetic energy"
- 需要更细致？→ 强调"meticulous detail"和"environmental storytelling"
- 需要更梦幻？→ 强调"impossible geometry"和"surreal color harmony"

### 微调方法4：季节和时间调整
```
添加时间参数：
- "golden hour sunlight filtering through windows"
- "cool blue morning light"
- "dramatic storm lighting"
- "neon-lit night atmosphere"
```

## 🔄 工作流建议

1. **选择美学类型**（A-E中的一个）
2. **选择场景具体描述**
3. **添加色彩/光影需求**
4. **叠加制作质量词**
5. **根据需要调整细节深度**
6. **测试和迭代优化**

每次测试后记录：
- 风格是否符合预期但不过度模仿
- 细节层次是否适当
- 色彩和光影是否有效
- 是否避免了廉价感
